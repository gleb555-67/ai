# 🎨 AI Image Generator Bot

Telegram-бот, который генерирует изображения по текстовому описанию с помощью
[Pollinations AI](https://pollinations.ai). Отправь боту любой промпт — и получи
готовую картинку прямо в чате.

## ✨ Возможности

- 🖼️ Генерация изображений по текстовому промпту (модель `google/gemini-nano-banana-2.1`)
- 💬 Простой и понятный интерфейс в Telegram
- ⚙️ Настраиваемые параметры: размер, seed, модель
- 🛡️ Обработка ошибок API (401, 402, 429 и др.)
- 🧹 Автоматическая очистка временных файлов
- 🔌 Поддержка прокси (SOCKS5 / HTTP)
